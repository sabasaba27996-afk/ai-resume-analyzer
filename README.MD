AI Resume Analyzer 🚀

An AI-powered Resume Analyzer designed to help job seekers evaluate their resumes and improve their ATS (Applicant Tracking System) compatibility.

🌐 Live Demo

"Try AI Resume Analyzer" (https://myresumely-ai.vercel.app)

📌 About the Project

AI Resume Analyzer is a web-based application that helps users understand how well their resumes align with ATS requirements.

The project focuses on simplifying resume evaluation and providing useful insights to help users improve their resumes.

✨ Features

- ATS Resume Analysis: Analyze resumes based on ATS-friendly formatting.
- Resume Evaluation: Get insights into your resume.
- Recommended Keywords: Identify relevant keywords to improve your resume.
- User-Friendly Interface: Simple and easy-to-use design.
- Web-Based Application: Access the tool through a browser.

🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Vite

💻 Installation and Setup

To run this project locally:

1. Clone the repository:
   
   git clone https://github.com/sabasaba27996-afk/ai-resume-analyzer.git

2. Navigate to the project directory:
   
   cd ai-resume-analyzer/ai_resume_starter_code

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in your terminal.
